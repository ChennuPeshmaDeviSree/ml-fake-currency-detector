## 📌 Project Overview
This project focuses on detecting fake bank currency using Machine Learning techniques. 
It uses multiple algorithms to classify banknotes as genuine or fake.

## 🚀 Features
- Detect fake vs genuine currency
- Uses multiple ML algorithms
- High accuracy prediction
- Easy-to-use interface

## 🧠 Algorithms Used
- KNN
- SVM
- Decision Tree
- Random Forest
- Logistic Regression
- Naïve Bayes
- LightGBM

## ⚙️ Technologies Used
- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib

## 📁 Project Files
- main.py → Main code
- banknotes.csv → Training dataset
- testdata.csv → Testing dataset
- Project_PPT.pdf → Project explanation

## 🔍 How to Run
1. Open the project
2. Run main.py
3. Upload dataset
4. Click algorithms to train
5. View results

## 🎯 Output
The system predicts:
- Genuine Currency
- Fake Currency
